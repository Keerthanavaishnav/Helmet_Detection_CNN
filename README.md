# Helmet Detection using Convolutional Neural Networks (CNN)

## Project Overview
This project implements a Convolutional Neural Network (CNN) to classify images into two categories:

- Wearing Helmet
- Not Wearing Helmet

The objective is to develop a deep learning model that can assist in automated helmet detection for road safety and compliance monitoring.

## Features

- Image classification using CNN
- Data preprocessing and augmentation
- Model training and validation
- Performance evaluation using classification metrics
- Prediction on unseen images

## Technologies Used

- Python
- Google Colab
- TensorFlow
- Keras
- NumPy
- Matplotlib
- OpenCV
- Scikit-learn

## Dataset

The project uses a helmet detection image dataset containing two classes:

- Wearing Helmet
- Not Wearing Helmet
  
The dataset is included in this repository under the `Dataset` folder.

Note: A sample of the dataset is included in this repository. The complete dataset used for training contained 300 images of each class.

## Project Workflow

1. Import required libraries
2. Load and preprocess the dataset
3. Build the CNN model
4. Configure the Model
5. Train the model
6. Evaluate model performance
7. Visualise the model perfoemance
8. Predict helmet usage on test images
9. Evaluated performance metrics
    

## Results

The trained CNN model successfully classifies images into helmet and non-helmet categories and demonstrates the application of deep learning for image classification tasks.
